# Калькулятор личных финансов

## Описание
Консольное приложение на Python для учёта доходов и расходов. Позволяет добавлять операции, просматривать их список и отслеживать текущий баланс.

## Установка и запуск
Требуется Python 3.8+.
```bash
git clone https://github.com/KatyaMasha/personal-finance-calculator.git
cd personal-finance-calculator
python src/main.py
